# 28 章逐篇内容与工程审查记录

本轮以现有正文为基线完成目录迁移、语义结构统一、独立图解、交互实验入口、章节目标、小结、方法边界提醒和延伸阅读。以下记录每章最需要继续核对的统计学风险点。**本轮加入了显式边界提醒，不代表已对所有旧段落、代码输出和引用完成逐句学术审校。**

| 章 | 主题 | 本轮重点检查与后续校准 |
|---:|---|---|
| 01 | 什么是统计学 | 区分总体、样本、描述与推断；避免把统计学描述成与数学相互排斥的学科。 |
| 02 | 数据类型与来源 | 核对名义、有序、等距、等比尺度；Likert 单题与多题量表的处理不能一概而论。 |
| 03 | 描述统计（一） | 核对均值、中位数、众数与方差；明确总体方差 n 与样本无偏方差 n−1 的差异。 |
| 04 | 描述统计（二） | 核对分位数、偏度、峰度和标准化；z-score 不会把偏态数据变成正态。 |
| 05 | 数据可视化基础 | 强化图形与摘要统计量的互补；核验 Anscombe 四重奏的图例与数据表达。 |
| 06 | 概率基础 | 核对条件概率与贝叶斯公式；阳性预测值必须考虑基准率。 |
| 07 | 常见概率分布 | 检查离散/连续分布、参数和生成机制；避免无条件套用正态近似。 |
| 08 | 抽样与抽样分布 | 纠正“n≥30 即正态”的机械规则；解释标准误与原始数据标准差的区别。 |
| 09 | 点估计与区间估计 | 复核矩估计与 MLE 的样本矩分母、偏差性质及置信区间解释。 |
| 10 | 假设检验入门 | 校准 p 值、显著性水平、单/双侧检验；不得把 p 值解释为零假设为真的概率。 |
| 11 | 常见假设检验 | 区分两样本方差比 F 检验与 ANOVA F 检验；核验检验选择、前提和精确方法。 |
| 12 | 统计功效与样本量 | 明确效应量、α、β、功效与样本量的共同依赖关系；核验功效代码。 |
| 13 | 相关分析 | 区分 Pearson 线性相关与 Spearman 单调关联；正态性主要涉及部分推断过程。 |
| 14 | 简单线性回归 | 复核 OLS 目标函数、R² 与残差诊断；避免把回归关联直接解释为因果。 |
| 15 | p 值与统计显著性危机 | 解释分析自由度、HARKing 与选择性报告；核验历史案例的原始来源。 |
| 16 | 多重比较与谬误 | 标明 FWER 乘法公式的独立性条件；区分 FWER 与 FDR 的目标。 |
| 17 | 因果推断基础 | 核验混杂、潜在结果、DAG 和 RCT；谨慎描述 HRT 等复杂证据案例。 |
| 18 | 统计伦理与最佳实践 | 对造假与撤稿案例逐一追溯调查/撤稿记录；避免未经证实的个人经历口吻。 |
| 19 | 多元线性回归 | 核验 VIF、共线性与交互项；经验阈值不是定律，预测与解释应区分。 |
| 20 | 逻辑回归 | 核验 logit、odds ratio、ROC/AUC；AUC 没有跨场景通用的好坏阈值。 |
| 21 | 方差分析（ANOVA） | 核验 F 统计量、方差齐性、自由度和事后比较；补充 Welch ANOVA 的适用情形。 |
| 22 | 贝叶斯统计入门 | 任何后验区间数字都必须由明确先验和数据计算；解释先验敏感性与 MCMC 诊断。 |
| 23 | 统计学工具链 | 检查点击率等比例数据是否被错误当作正态连续数据；代码与数据生成过程要匹配。 |
| 24 | 真实数据分析实战 | 核验数据集来源、缺失处理和模型诊断；说明缺失机制与简单插补的风险。 |
| 25 | A/B 测试实战 | 核验比例检验与样本量代码；补充样本比例失衡、重复查看、护栏指标和停止规则。 |
| 26 | 机器学习中的统计学 | 限定 Bias–Variance 分解的平方损失条件；核验正则化、交叉验证与泛化解释。 |
| 27 | 现代因果推断 | 分别检查 PSM、DID、RDD 的识别假设、诊断与敏感性分析。 |
| 28 | 综合项目：从问题到结论 | 强制区分描述、预测与因果目标；观察性数据不能自动支持因果结论。 |
