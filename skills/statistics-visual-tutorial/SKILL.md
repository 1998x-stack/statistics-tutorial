# Statistics Visual Tutorial

本 Skill 是统计学教程的专用生产规范。它迁移 Olah-style-posts 的问题驱动叙事、逐步图解、数学语义、可执行示例和浏览器验收方法，但不照搬论文解读模板。目标读者为大学生与初学研究者：解释要直观、严谨、可验证，不堆砌术语。

## 核心原则

**研究问题与统计正确性 > 概念递进 > 图解可读性 > 数学表达 > 交互体验 > 视觉装饰。**

- 每篇文章开头必须说明题目在解决什么问题，不能只放标题。
- 先解释数据如何产生、研究问题是什么，再介绍统计量或模型。
- 区分总体参数、样本统计量、估计量、估计值、预测值和因果效应。
- 区分描述统计、推断统计、预测建模与因果识别。
- 所有模拟都标注为教学示例；无来源的历史、行业和经验数字不得写成事实。
- 每章 SVG 必须有该主题独有的统计语义，不能只换图中文字。
- 交互是渐进增强：无 JavaScript 时，文章和静态图仍可理解。

## 必须执行的工作流

### Gate 0 — 现状与来源审查
1. 阅读目标章节、课程目录、前后章节、共享 CSS/JS 和 AGENTS.md。
2. 识别核心问题、先备知识、易错点和适用边界。
3. 查阅 OpenStax、NIST、ASA、原始论文或官方软件文档，优先一手来源。
4. 为关键概念、公式、经验数值建立 evidence ledger。未核实条目标为 unverified。

### Gate 1 — 设计学习路径
按“具体困惑 → 数据与研究设计 → 直觉图示 → 统计量/模型 → 数学表达 → 例子或实验 → 假设与边界 → 小结”组织。
- 每一节只解决一个主要问题。
- 解释方法为何适用，而不只是给出公式。
- 至少包含一个反例、失败模式或适用条件。
- 前置知识通过课程地图链接，不重复堆砌全课程目录。

### Gate 2 — 统计正确性审查
逐项检查抽样方式、独立性、选择偏差、变量定义、分母、自由度、条件事件、尾部方向和模型假设。
- p 值不是零假设为真的概率；置信区间不是固定参数的随机概率陈述。
- 不拒绝零假设不等于证明零假设；统计显著不等于实际重要。
- 相关性和回归系数不自动具有因果解释。
- 多重检验、提前窥视、缺失数据、聚类和重复测量都可能改变推断。
- 因果方法必须明确识别假设，不能只罗列方法名称。

### Gate 3 — 语义 HTML 与页面结构
- 使用 HTML5、lang=zh-CN、唯一 H1、合理 H2/H3 层级。
- 文章位于 chapters/<slug>/index.html；每章配套 assets/overview.svg 与 evidence.json。
- 每篇含学习目标、本章路线、正文、交互实验、小结和延伸阅读。
- 共享样式放 assets/css/article.css，交互放 assets/js/article.js。
- 不依赖 CDN、远程字体、外部追踪或在线数学脚本；页面必须可离线阅读。
- 保留旧的 01.html 至 28.html 路径为兼容跳转页。

### Gate 4 — SVG 与数学表达
- SVG 必须包含 xmlns、viewBox、title、desc、可访问标签和图注。
- 轴、样本、分布、区间、拒绝域、散点和因果箭头必须符合本章统计含义。
- 复杂公式优先使用浏览器原生 MathML；分式、求和、下标、上标和根号必须用真实结构。
- 长公式置于可键盘滚动的区域；不把 MathML 放进 SVG。

### Gate 5 — 可交互教学实验
- 每章至少一个有明确教学问题的交互；控件有 label、范围、默认值和 aria-live 结果。
- 输出随输入变化，并说明固定参数、假设与限制。
- 不把概念演示伪装为正式统计分析、功效计算或真实研究结论。
- 支持键盘操作；无 JavaScript 时仍可阅读静态图和解释。

### Gate 6 — 静态与浏览器验收
检查 1440、768、390、360px 布局；SVG；MathML 命名空间与滚动；目录锚点；前后章链接；离线打开；控制台错误；交互输入输出。
记录 passed / failed / not verified。没有运行的检查不能声称通过。

### Gate 7 — 发布
逐篇检查改动，不以批量模板替代内容审校。运行 Node 静态测试和 Playwright 浏览器检查。PR 中列出改造章节、已验证项目、未验证风险和回滚路径。只有确认 GitHub Pages 实际部署成功后，才能称为已上线。

## 质量红线
- 不编造样本量、经验比例、历史故事、研究结论或企业案例。
- 不把 p<0.05 写成结论可靠性的充分条件。
- 不将统计相关、预测能力或模型拟合优度直接表述为因果效应。
- 不隐藏失败的浏览器测试，不以弱化断言制造通过。
- 不因视觉改版删除原文中正确且必要的统计推导。
- 每篇文章都必须说明至少一个关键假设或方法边界。
