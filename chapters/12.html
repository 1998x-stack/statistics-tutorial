Chapter 12 · Power

统计功效与样本量：别让真效应溜走

“p > 0.05”不等于“没有效果”。如果实验没有足够的能力去发现真实效应，那一次“不显著”只是信息不足，而不是反证。

贯穿案例：一个教育干预实验每组只有 30 人，结果 p = 0.24，团队宣布“新方法无效”。如果真实效应是 Cohen's d = 0.4，这个实验有多大概率能检出它？答案会改变整个结论。

01 · 功效是“检出的概率”

统计功效（statistical power）的定义很直接：当真实效应确实存在时，检验能正确拒绝 H₀ 的概率。它是 1 减去第二类错误率 β。

Power=1−β
式 1
假设检验的四种结局
H₀ 实际为真H₀ 实际为假
拒绝 H₀第一类错误（假阳性，概率 α）正确 → 功效 1−β
不拒绝 H₀正确（概率 1−α）第二类错误（假阴性，概率 β）

02 · 决定功效的四个因素

功效不是单一数字，而是由四个相互牵连的量决定的：

  1. 效应量：真实差异越大，越容易检出，功效越高。
  2. 样本量：样本越大，标准误越小，功效越高。
  3. 显著性水平 α：放宽 α（如 0.10）会提高功效，代价是更多假阳性。
  4. 检验方法与假设：配对设计、单侧检验或更合适的模型都能提高功效。

知道其中三个，就能求第四个。最常见的情形是：根据实际意义确定要检测的效应量，固定 α = 0.05，要求功效至少 0.80，然后倒推所需样本量。

0.80 不是定律

“功效至少 0.80”来自 Jacob Cohen 1988 年的经典建议（此时 β = 0.20）。它是惯例，不是自然常数：涉及安全的药物试验应追求 0.90 甚至更高，而探索性的预研究可以接受更低。

一个有助于警醒的经验数据：Button 等（2013）对神经科学文献的综述估计，相关研究的中位统计功效约为 21%。也就是说，若这些效应真实存在，大多数研究本就没有足够能力稳定地发现它们。

03 · 效应量：d 与 r

p 值回答“有没有效果”，效应量回答“效果有多大”。在超大样本里，一个 p < 0.0001 的结果，效应量可能小到毫无实际意义；反过来，小样本即便效应很大也可能给不出小 p 值。

d=x¯1−x¯2sp
式 2

常用经验基准（Cohen）：Cohen's d 为 0.2 / 0.5 / 0.8 分别对应小 / 中 / 大效应；相关系数 r 为 0.1 / 0.3 / 0.5 类似；ANOVA 则用 Cohen's f。这些只是参照尺度，实际意义要看领域：教育干预里 d = 0.4 已经不小，而某些物理测量里 d = 0.4 可能微不足道。

胜利者的诅咒

用小规模预实验估出的效应量往往被高估：只有“看起来很大”的随机波动才容易被看到。若直接拿这个偏大的 d 去设计正式实验，会低估所需样本量，进一步导致功效不足。

04 · 样本量估算

对两样本均值比较，每组所需样本量可用下面的正态近似快速估算：

n≈2(z1−α/2+z1−β)2d2
式 3

取 α = 0.05（双侧）与功效 0.80，则 z₁₋α/₂ ≈ 1.96、z₁₋β ≈ 0.84，因而 n ≈ 15.7 / d²。把它代入不同效应量，得到下面的对比：

from math import erf, sqrt

def Phi(z):            # 标准正态分布函数
    return 0.5 * (1 + erf(z / sqrt(2)))

def inv_Phi(p):        # 用二分法求分位点
    lo, hi = -10.0, 10.0
    for _ in range(80):
        m = (lo + hi) / 2
        if Phi(m) < p: lo = m
        else: hi = m
    return (lo + hi) / 2

def n_per_group(d, alpha=0.05, power=0.8):
    za = inv_Phi(1 - alpha/2); zb = inv_Phi(power)
    return 2 * (za + zb)**2 / d**2

for d in (0.2, 0.5, 0.8):
    print(d, round(n_per_group(d), 1))   # 392.4  62.8  24.5

上式是正态近似；实际的 t 检验（尤其小样本）会略大一些，功效软件给出的常用值为 394、64、26。精确计算需要非中心 t 分布，可用 statsmodels 的 TTestIndPower().solve_power() 或 G*Power 完成。

05 · 为什么多数研究功效不足

  1. 经费与时间：招募更多被试需要更多成本，于是样本被压到很小。
  2. 效应量被高估：拿小规模预实验的 d 去设计正式实验，而小样本的 d 往往偏大（胜利者的诅咒）。
  3. 缺乏规划：很多研究在收集数据前根本没做功效分析。
  4. 发表偏倚：显著结果更容易发表，反过来降低了对功效的重视。

“不显著”不等于“没效果”

若某实验的功效只有 30%，那么当效应真实存在时，它有 70% 的概率给出“不显著”。把这类结果当成“证明无效”的证据，是常见的推理错误。要声称“无效果”，应做等价性检验并报告置信区间，而不是只看 p 值。

可操作的三步：查文献确定合理的效应量范围；用功效分析算出所需样本量；把样本量与分析计划预先注册。这样既能约束事后挑选，也能让结论更可信。

06 · 动手：功效计算器

拖动效应量 d 与每组样本量 n，观察两样本 t 检验的近似功效。这里用正态近似：若非中心参数 λ = d√(n/2)，则双侧功效约为 Φ(λ − z₀.₉₇₅) + Φ(−λ − z₀.₉₇₅)。

07 · 自我检查与可复现计算

from math import erf, sqrt
Phi = lambda z: 0.5 * (1 + erf(z / sqrt(2)))

def power(d, n, alpha=0.05):        # 两样本 t 检验的正态近似
    zc = 1.959964
    lam = d * sqrt(n / 2)
    return Phi(lam - zc) + Phi(-lam - zc)

print(round(power(0.5, 64), 3))     # 0.807  ≈ 80%
print(round(power(0.4, 30), 3))     # 0.336  ≈ 34%
print(round(15.7/0.4**2, 1))        # 98.1   达 80% 功效所需每组人数

自我检查

问题：一个实验每组 n = 30，若真实效应是 Cohen's d = 0.4，这个实验的统计功效约为多少？

参考答案：约 0.34。非中心参数 λ = 0.4×√(30/2) ≈ 1.55，双侧功效 ≈ Φ(1.55−1.96) ≈ Φ(−0.41) ≈ 0.34。也就是说即使方法真的有效，这个实验也只有约三分之一的机会检出它——这时“p > 0.05”几乎不能说明任何问题。

失败模式

事后（post-hoc）功效是无用的：它仅由已得 p 值和样本量决定，不能告诉你研究实际有多可信。正确做法是在设计阶段做先验功效分析，并在报告中同时给出效应量的置信区间。
