Chapter 26 · ML and statistics

机器学习中的统计学：偏差、方差与正则化

机器学习里的“黑科技”大多不是凭空出现的：偏差-方差、正则化、交叉验证，都是统计学概念在预测任务里的重新命名。看清这层对应，才能理解模型为什么“这么设计”。

贯穿案例：一个 20 阶多项式模型在训练集上 R² = 0.998，换到新数据却差得离谱。同样的拟合能力，为什么会“翻车”？

01 · 推断与预测：同一枚硬币

统计学习与机器学习关注同一个目标——从数据学到可推广的规律，但侧重点不同。统计推断想回答“X 如何影响 Y”并给出可解释的参数与不确定性；机器学习更关心“在没见过的数据上预测得准不准”。两者不是对立的，而是同一套工具在不同目标下的使用。把常见算法翻开看，底层大多是统计学：

机器学习算法与统计学基础
方法统计学基础
线性回归最小二乘、极大似然
逻辑回归广义线性模型、优势比
Ridge / LassoL2 / L1 正则化、高斯 / Laplace 先验
随机森林方差分解、Bagging 降方差
梯度提升加性模型、函数空间梯度下降
K-MeansEM 算法、混合模型
PCA协方差矩阵的特征分解

同一个模型，目标变了，评价方式也跟着变：推断看重系数与区间是否可信，预测看重在保留集上的泛化误差。下一节的偏差-方差分解正是预测视角的核心。

02 · 偏差-方差分解

对一个新观测点，预测误差的期望可以拆成三部分：

E[(y−y^)2]=Bias2+Var+σ2
式 1

偏差 Bias

模型对真实关系的简化。模型太简单就会高偏差，表现为欠拟合（如用直线拟合曲线关系）。

方差 Var

模型对训练数据波动的敏感程度。模型太复杂就会高方差，表现为过拟合（如记住每个训练点）。

第三项 σ2 是数据本身的噪声，任何模型都消不掉。随着模型复杂度上升，偏差下降、方差上升，总误差呈现 U 形曲线：

失败模式：训练集上的完美

一个 20 阶多项式可以把训练点记到几乎无误差，但新数据上误差很大——这是高方差的典型。一个合成示意：训练集 R² 高达 0.998，换到新数据后预测偏离很大；降到 5 阶加交叉验证后，训练 R² 虽低（如 0.87），但泛化更稳。训练集上的“完美”往往是灾难的开始。

上述 R² 数值为合成教学示意，不是一个真实项目的结果。

03 · 正则化就是先验

正则化（regularization）是控制复杂度的常用手段。它通过在损失里加一个惩罚项来限制参数大小：

J(θ)=∑iLoss(yi,y^i)+λ‖θ‖2
式 2

Ridge 用参数的平方和（L2，上式的 λ‖θ‖2），Lasso 用绝对值之和（L1）。从第 22 章的贝叶斯视角看，它们分别对应不同的先验：

L2 ≈ 高斯先验

假设权重服从均值为 0 的正态分布，惩罚大权重但不把任何一个精确压到 0，结果通常是“都小一点”。

L1 ≈ Laplace 先验

Laplace 分布在 0 处有尖峰，倾向于把不重要特征的权重精确压为 0，因而能自动做特征选择（稀疏解）。

正则化不是“技巧”，是含了先验

给权重加 L2 惩罚，等价于相信“权重不会太大”；加 L1 惩罚，等价于相信“大多数特征影响很小”。这正是贝叶斯后验最大化在特定先验下的形式。理解这一点，就能解释正则化为什么有效，而不是把它当黑魔法。

04 · 交叉验证：诚实的评估

用训练数据评估模型必然乐观：模型已经见过这些点。交叉验证把数据分成 K 份，轮流拿一份做验证、其余训练，最后汇总，从而近似泛化误差的期望。

变体各有取舍：留一法（LOOCV）偏差小但计算量大且方差可能偏高；分层 K 折适合不平衡分类；时间序列不能随机划分，必须用“过去训练、未来验证”的滚动方式，否则会用到未来信息。

失败模式：数据泄露

在划分之前就用全量数据做了标准化、特征选择或缺失值插补，会把验证集的信息渗进训练，得到虚高的 CV 分数。正确做法：把预处理写进管线，在每一折内部只用训练部分拟合变换。

05 · 梯度提升的统计学视角

梯度提升（gradient boosting）在过去十年统治了表格数据竞赛。它的统计骨架很古典：一个加性模型逐项拟合。

F(x)=∑t=1Tft(x)
式 3

每一轮在前一轮的残差（更严格地说，是损失函数在当前预测处的负梯度）上拟合一个新的弱学习器（通常是浅树），然后加到总模型里。这可以看成“函数空间中的梯度下降”；学习率与树深度、子采样一起控制复杂度，仍然回到偏差-方差的权衡。

XGBoost 相对传统 GBDT 的关键改变是在目标里加入了显式正则化（叶节点数与叶权重的 L2 项）。这正好就是第 3 节讲的正则化：用惩罚项限制模型复杂度，防止过拟合。

“黑科技”也有统计根源

Dropout 可解释为一种近似的贝叶斯模型平均（Gal & Ghahramani, 2016）；Batch Normalization 的动机之一是控制内部协变量偏移（Ioffe & Szegedy, 2015）。把新方法放回统计学框架，更容易判断它什么时候会失灵。

06 · 动手：复杂度与误差

下面用一个教学函数把偏差、方差与总误差的关系画成可调的形式：拖动复杂度，看偏差²下降、方差上升，总误差先降后升。

偏差-方差 vs 复杂度

教学函数：偏差² = 1.2(1 − c/10)²，方差 = 1.2(c/10)²，噪声固定 0.2；总误差 = 三者之和。不含随机数。

在 c 很小处，总误差主要来自偏差（欠拟合）；在 c 很大处，主要来自方差（过拟合）。最优复杂度在两者大致相等的地方，这正对应图 1 的 U 形最低点。

07 · 自我检查与可复现计算

用下面的代码重现演示中的函数，直接看出最优复杂度大约在哪里。

for c in [0, 3, 5, 7, 10]:
    bias2 = 1.2 * (1 - c / 10) ** 2
    var = 1.2 * (c / 10) ** 2
    total = bias2 + var + 0.2
    print(c, round(bias2, 3), round(var, 3), round(total, 3))
# c=0: 1.200 0.000 1.400
# c=5: 0.300 0.300 0.800   <- 总误差最小
# c=10: 0.000 1.200 1.400

总误差在 c = 5 处最小（0.8），两端都升到 1.4。这提醒你：提高模型容量不一定降低泛化误差。

# 用 K 折交叉验证估计泛化误差（scikit-learn）
from sklearn.model_selection import cross_val_score
from sklearn.linear_model import Ridge

# X, y 为你的数据；五折 CV 的平均负 MSE 即泛化误差估计
scores = cross_val_score(Ridge(alpha=1.0), X, y, cv=5,
                         scoring="neg_mean_squared_error")
print("CV MSE =", round(-scores.mean(), 4))

自我检查

问题：你在训练集上得到 R² = 0.998，能直接说模型很好吗？

参考答案：不能。高 R² 可能只是过拟合（高方差）。应在保留集或交叉验证上评估；若泛化误差远大于训练误差，就该降低复杂度或加正则化。

失败模式：用全量数据做预处理

划分前对全体数据标准化/选特征/插补，会泄漏验证集信息，CV 分数虚高。把预处理放进可重复管线，每折内只用训练部分拟合变换。
