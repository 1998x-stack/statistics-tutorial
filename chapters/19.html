Chapter 19 · Multiple regression

多元线性回归：控制其他变量之后

简单回归用一条直线解释一个自变量。现实里房价同时取决于面积、地段、房龄；把更多变量放进模型并不自动让结论更可靠——它改变了每个系数到底在回答什么问题。

贯穿案例：某公司想估计“多工作一年能多赚多少”。只用工作年限做回归，斜率是 1.9 万元；再加入教育年限后，斜率降到 1.2 万元。这两个数都是对的——它们回答的是不同的问题。

01 · 从简单回归到多元回归

简单线性回归用一条直线拟合一个自变量：y=β0+β1x+ε。多元线性回归（multiple linear regression）在同一模型里放进 p 个自变量，拟合的对象从一条直线变成一张（高维）平面：

y=β0+β1x1+β2x2+⋯+βpxp+ε
式 1

注意这里说的是“多元回归”（多个自变量、一个因变量），不是“多变量回归”（multivariate regression，多个因变量同时建模）。中文里两者都常被译成“多元”，容易混淆，读英文文献时要看清是 multiple 还是 multivariate。

为什么不能把单变量斜率直接拿来用

只用工作年限预测年薪，斜率为 1.9 万元/年；但工作年限长的人通常也受教育更久，这个 1.9 里混进了教育的贡献。加入教育年限后剩下来的 1.2 万元/年，才是“教育相同时”多一年工作年限的关联。两个数都不是错的，只是前面的那个把两件事叠在了一起（第 17 章的遗漏变量偏倚）。

02 · 偏回归系数：控制其他变量

多元回归里的系数叫偏回归系数（partial regression coefficient）。它的含义是：在其余自变量取固定值时，某个自变量增加一个单位，y 的平均变化量。这个“固定其余”不是语义上的修饰，而是最小二乘估计的数学结果。

给定设计矩阵 X（第一列为全 1，其余列为各自变量）与响应向量 y，使残差平方和最小的系数向量为：

β^=(XTX)−1XTy
式 2

式 2 假定了 X 的列满秩。如果两列完全相等（或某列是其他列的线性组合），XTX 不可逆，模型无法给出唯一解——这正是下一节共线性的极端情形。

简单回归斜率

回答：“y 和 x₁ 一起怎么变？”它包含 x₁ 与其他变量的混杂效果。上面例子中的 1.9 万元/年就属于这一类。

偏回归系数

回答：“在 x₂, x₃ … 相同的子群体里，y 随着 x₁ 怎么变？”这是 1.2 万元/年的含义。

“控制”不等于 causal

把变量放进模型只会让比较在观测到的变量上“更公平”，不会自动处理你没测到的混淆变量、也不保证因果方向。只有在随机化或可信的识别策略下，偏回归系数才可能被赋予因果解释（第 27 章）。

03 · 多重共线性与 VIF

自变量之间高度相关时，模型很难分辨“功劳该归给谁”。两列几乎提供相同信息，系数的点估计可能大幅来回跳动，符号甚至翻转为反直觉的方向。这不是程序出错，而是数据里本来就不够信息把它们分开。

常用的诊断量是方差膨胀因子 VIF：把第 j 个自变量对其余所有自变量做回归，得到 Rj2，则

VIFj=11−Rj2
式 3

VIF 的含义是：该系数估计的方差相对于“自变量彼此不相关”时被放大了多少倍。若 Rj2 = 0，VIF = 1，无膨胀；Rj2 = 0.9 时 VIF = 10。教科书常用“VIF > 10”作为需要关注的粗略阈值，但它是经验规则，不是硬边界。

教学示意的 VIF 诊断表（非真实数据）
自变量VIF判断含义
工作年限2.3正常与其他变量低相关
教育年限1.8正常相对独立
每周加班小时1.2正常几乎独立
同事评分9.8临界可能值得检查
上一个岗位工资14.5偏高与工作年限强相关

多项式项是“结构性”共线，不必紧张

加入 x 与 x2 时，两者必然相关，VIF 会很高。这是模型设计带来的结构相关，不是数据缺陷；通常改成中心化（减去均值）后再构造平方项就能缓解大多数数值问题。把 VIF 当成“所有高值都要删变量”的自动规则，反而会损坏模型。

04 · 交互项：效应不是简单相加

式 1 隐含一个假设：每个自变量的效果是可加的——x₁ 的作用大小不依赖于 x₂ 取什么值。很多时候这不成立。教育年限对收入的回报，可能在高科技行业比传统行业更高，这时的效果依赖于“行业”这个变量。

把交互写进模型，就是在右边再加一项乘积：

y=β0+β1x1+β2x2+β3x1x2+ε
式 4

此时 x₁ 每增加一个单位，y 的平均变化量是 β1+β3x2：它不再是一个常数，而是随 x₂ 变化的一条线。因此单独读 β₁ 已经没有“主效应”那么简单，必须结合 β₃ 一起解释。

中心化后再放交互项

当 x₁、x₂ 取值较大（例如 1000 量级的面积）时，乘积项会很大且与其主效应高度相关。把自变量先中心化（各自减去均值）再相乘，能让 β₁、β₂ 在“另一变量取均值”处有意义，也能降低数值上的共线性，不改变模型的拟合。

05 · 模型选择：AIC、BIC 与逐步回归

候选自变量很多时，需要一套“取舍拟合与复杂度”的量。AIC 与 BIC 都在对数似然上减去一个惩罚项（越小越好）：

AIC=−2lnL+2k,BIC=−2lnL+klnn
式 5

其中 L 是拟合模型的最大似然，k 是参数个数（含截距），n 是样本量。ln(n) > 2 时（即 n > 7），BIC 对多参数的惩罚比 AIC 更重，因而倾向于更简约的模型。两者都只能比较“同一份数据、同一个响应变量”下的候选模型，数值本身没有绝对意义。

一种常见做法是逐步回归：向前逐个加变量、向后逐个删变量，或两者结合，按 AIC 等指标一步一选。但这个过程本身就是大量数据驱动的比较：最终模型的 p 值、置信区间和 R² 都因“选择”而不再是常规分布下的量，容易过拟合、也难以重复。

失败模式：把逐步回归的系数当成常规推断

逐步回归挑选变量后直接报告系数与 p 值，会系统性夸大显著性。更稳的做法是：先用领域知识定下候选自变量，再用 AIC/BIC 在小范围内比较，最后用交叉验证（第 26 章）评估预测表现。选择变量用过数据，就不能再假装没见过数据。

06 · 动手：共线性如何放大标准误

只有两个自变量时，VIF 与它们的相关系数 ρ 有一个闭式关系：VIF=11−ρ2。拖动滑块，看系数标准误被放大多少倍。

相关系数与标准误膨胀

此处只含两个自变量，VIF = 1/(1−ρ²) 是精确公式而非近似；标准误约为不相关情形的 √VIF 倍。滑块只改参数，不含随机数。

把 ρ 推到 0.9 以上，VIF 迅速超过 5，标准误也被放大 3 倍以上。这直接表现为置信区间变宽：“数据不足以分辨两个变量的贡献”并不是算法问题，而是信息量问题。

07 · 自我检查与可复现计算

下面的代码用最小二乘直接算 VIF：把第 j 个自变量对其余自变量回归，求残差平方和解释的比例，再取倒数。只要 NumPy 即可重现（随机数已固定）。

import numpy as np

rng = np.random.default_rng(19)
n = 200
z = rng.normal(size=n)
x1 = z + rng.normal(scale=0.2, size=n)   # 与 x2 高度相关
x2 = z + rng.normal(scale=0.2, size=n)
x3 = rng.normal(size=n)                  # 与其余基本无关
y = 1 + 2*x1 - x2 + 0.5*x3 + rng.normal(scale=0.1, size=n)

X = np.column_stack([np.ones(n), x1, x2, x3])

def vif(X, j):
    yj = X[:, j]
    Xo = np.delete(X, j, axis=1)
    beta, *_ = np.linalg.lstsq(Xo, yj, rcond=None)
    resid = yj - Xo @ beta
    r2 = 1 - resid.var() / yj.var()
    return 1 / (1 - r2)

for name, j in [("x1", 1), ("x2", 2), ("x3", 3)]:
    print(name, round(vif(X, j), 1))

预期结果：x1、x2 的 VIF 很高（因为两者几乎共线），x3 接近 1。这提醒你：即使数据量很大，只要两列信息重合，系数依然“分不清功劳”。

自我检查

问题：同事报告了一个模型，其中“卧室数”的系数为负：“房间越多房子越便宜？”他应该先检查什么？

参考答案：先算“卧室数”与“总面积/总房间数”等变量的 VIF。若两者高度共线，系数就可能偏离真实方向。删去重复变量或改用正则化后，再重新解释。
