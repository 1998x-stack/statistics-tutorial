Chapter 28 · End-to-end project

综合项目：从问题到结论的完整流程

前 27 章给了你工具。真正做项目时，决定结论质量的往往不是某个检验选得对不对，而是那些更早的决定：问题问得清不清楚、数据能不能回答它、分析计划有没有提前写下来。

贯穿案例：一个数据集记录了 2000 人的运动频率与 BMI。想回答“运动是否影响 BMI”，直接跑一个相关或回归就够了吗？如果年龄既影响运动、也影响 BMI，简单分析会告诉我们什么？

01 · 从模糊的好奇到可检验的问题

“运动到底有没有用”不是一个统计问题，因为它无法被数据否定。研究的第一步，是把好奇改写成一个可量化、有对比、能被数据反驳的问题。好的研究问题通常具备三个特征：可量化（能定义出具体的变量与单位）、有对比（至少两个可比较的情形）、有不确定性（答案不是显而易见，否则不需要统计）。

把例子改一下：“在控制年龄与性别后，每周多运动一天，成年人的 BMI 平均变化多少？”——这句话已经隐含了变量、对比与一个需要估计的参数。接下来的所有工作，都是围绕它展开。

02 · 研究设计：先写假设，再碰数据

初学者最容易跳过这一步——拿到现成数据就直接跑模型。这就像没有地基就盖楼。研究设计要事先回答五个问题，而它们的答案必须写在看到结果之前：

  1. 假设是什么？把零假设 H₀ 与备择假设 H₁ 写清楚，并指明是单侧还是双侧。
  2. 数据从哪里来？实验还是观测？若是观测数据，哪些变量可能混杂，怎么处理？
  3. 样本量够吗？用第 12 章的功效分析，给出能检出的最小效应与相应样本量。
  4. 分析什么？描述用哪些图表、推断用哪个检验或模型、是否需要控制变量。
  5. 能不能预先注册？把分析计划公开记录，减少选择性报告与 p-hacking。

把设计写下来还有一层好处：它迫使你把“问题”翻译成“可执行的分析”——变量怎么定义、样本怎么纳入、缺失怎么处理、主分析之外还会做哪些敏感性分析。一个被严重低估的技巧是：在接触真实数据之前，先生成一批模拟数据把分析流程跑通，用它验证方法是否合适、样本量是否够、代码有没有错。

失败模式：用结果反推设计

“先跑十种模型，挑出显著的那个，再补一段‘我们假设……’”会系统性抬高假阳性。预注册与多重比较校正（第 16 章）正是为对付这类做法而存在。

03 · 分析流程：探索、建模、诊断

数据到手后，流程分三步，每一步都有它不能跳过的交付物：

  1. 探索性分析（EDA）：先看单变量分布、缺失、异常值，再看变量间的关系。图表优先，因为数字摘要会掩盖曲率与聚类（第 5 章）。
  2. 建模与估计：根据问题选模型，报告系数（或效应量）及其置信区间，而不只报一个点估计与 p 值。
  3. 诊断与稳健性：检查残差是否近似正态、是否异方差、是否自相关；再用不同模型、子样本或不同假设重跑，看结论是否稳定。
各阶段的交付物与检查要点
阶段交付物检查要点
探索分布图、关系图有异常值吗？有混合群组吗？
建模系数、标准误、置信区间假设满足吗？效应量多大？
诊断残差图、Q–Q 图、诊断统计量正态、等方差、无自相关？
稳健性敏感性分析与替代模型结论稳定吗？替代解释能排除吗？

下一步用一个具体例子，把“探索→建模→诊断”走完，并看一个最常见也最容易被忽视的陷阱：混杂。

04 · 混杂的例子：运动与 BMI

回到贯穿案例。年龄既可能与运动频率相关（年轻人运动更多），又影响 BMI（新陈代谢不同），因此它是一条混杂路径。把变量关系画成有向无环图（DAG），能把“控制什么”从直觉变成可讨论的结构：

把控制年龄、性别后的模型写出来，目标参数是运动天数对应的系数：

BMIi=β0+β1⋅exercisei+β2⋅agei+β3⋅genderi+εi
式 1

而只用运动一个变量的“朴素”回归，会得到一个被污染的系数。在简化情形下，两者的差距约等于“年龄对 BMI 的效应 × 年龄与运动的关联”：

β^1≈β1+γ2⋅δ1
式 2

这里 β1 是真实的运动效应，γ2 是年龄对 BMI 的效应，δ1 是年龄与运动的关联。只要这两项都不为零，不控制的估计就有偏——哪怕样本量再大。

失败模式：把“调整后的相关”当成因果

控制变量也不是越多越好：控制一个“处理后变量”或“共同结果”，反而会引入新的偏倚。判断该控制什么，靠的是对数据生成机制的理解与 DAG，而不是把所有列都丢进模型。

05 · 报告：诚实呈现不确定性与局限

分析完成不等于项目完成。一份能被信任的报告，核心不是把图表做得好看，而是让读者能判断“这个结论能推到什么范围”。四条原则：

  • 结论先行：把“发现了什么”放在最前面，方法与细节放后面；决策者需要先知道答案。
  • 用区间而非单点：报告效应量及其置信区间，不把注意力全给 p 值（第 9、15 章）。
  • 诚实面对不确定性：结论不能比数据支持的更强；主动写出局限、替代解释与未排除的威胁。
  • 知道受众：给决策者的报告需要行动建议与可视化，给同行的报告需要方法细节与诊断。

报告自查清单

你的报告是否回答了：（1）为什么问这个问题？（2）数据来自哪里、有什么局限？（3）用了什么方法、为什么？（4）发现了什么，不确定性多大？（5）这意味着什么、应做什么？（6）还有哪些替代解释与未排除的威胁？

最后一步往往被忽略：把数据、脚本与版本一并归档，让别人能重跑。第 23 章讲过，不能复现的结论，只能算“一次性表演”。

07 · 自我检查与可复现计算

下面这段代码只用标准库，完全确定性，可以手算核对。它构造一份无随机噪声的合成数据（数据生成时真实运动系数固定为 −0.5），分别算“只看运动”与“控制年龄后”的斜率：

ages = [25, 30, 35, 40, 45, 50, 55, 60]
pert = [0.3, -0.2, 0.1, -0.3, 0.2, -0.1, 0.3, -0.2]
exercise = [round(3 - 0.05*(a-40) + p, 2) for a, p in zip(ages, pert)]
bmi = [round(28 - 0.5*e + 0.05*(a-40), 3) for a, e in zip(ages, exercise)]

def ols(xs, ys):                     # 一元最小二乘：返回斜率与截距
    mx, my = sum(xs)/len(xs), sum(ys)/len(ys)
    b = sum((x-mx)*(y-my) for x, y in zip(xs, ys)) / sum((x-mx)**2 for x in xs)
    return b, my - b*mx

def resid(xs, ys):                   # 对 xs 回归后的残差（用于 FWL）
    b, a = ols(xs, ys)
    return [y - (a + b*x) for x, y in zip(xs, ys)]

naive, _ = ols(exercise, bmi)        # 不控制年龄：-1.335
adj, _ = ols(resid(ages, exercise), resid(ages, bmi))   # 控制年龄：-0.5
print(round(naive, 3), round(adj, 3))   # -1.335 -0.5

未控制的系数 −1.335 比真实的 −0.5 夸大了近两倍，因为年龄既与运动反向相关，又抬高了 BMI。控制年龄后系数回到 −0.5，与数据生成时的设定一致——这就是混杂被挡住后应有的结果。

自我检查

问题 1：样本量从 2000 增加到 20000，上例中未控制的系数会不会谌渐逼近 −0.5？参考答案：不会。样本量只减少随机波动，不消除系统偏倚；只要混杂存在，大样本只会把错误的值估得更精确。

问题 2：既然多控制变量可能引入新偏倚，那么“把所有可用变量都放进回归”是安全的做法吗？参考答案：不安全。控制处理后变量或共同结果会引入新的选择性偏倚；应依据因果图与数据生成机制选择协变量，而不是全量堆入。
