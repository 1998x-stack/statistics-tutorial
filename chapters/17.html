Chapter 17 · Causal inference

因果推断基础：从相关到干预

两件事相关，至少有四种解释：X 导致 Y、Y 导致 X、存在同时影响两者的第三个变量，或者纯属巧合。因果推断的核心任务，就是逐一排除其他解释。

贯穿案例：观察性研究显示，接受激素替代疗法的女性冠心病风险更低；随机对照试验却得到相反结论。哪一个可信？为什么样本再大、p 值再小，也救不了混杂？

01 · 相关不等于因果

两个变量同时变化，并不能告诉我们谁影响谁，更不能排除第三个变量。把“相关”拆开来看，至少有四种解释，而观测数据本身无法直接分辨它们。

“冰淇淋销量与溺水人数同步上升”是最常被引用的一例：真正同时推动两者的是气温。Tyler Vigen 收集了大量这类虚假相关，用它们提醒读者：相关系数再高，也不能代替对机制的追问。

排除其他解释，而不是寻找相关

因果推断的任务不是“找到一个显著相关”，而是穷尽其他解释：有没有反向因果？有没有共同原因？样本选择是否引入偏倚？只有在这些都站不住脚时，因果结论才值得考虑。

02 · 混杂与 HRT 教训

混杂变量（confounder）是同时影响处理变量 X 和结果变量 Y 的第三个变量。只要它存在，X 与 Y 之间的相关就可能完全是虚假的。混杂无法靠增大样本量消除——它不会随 n 变大而衰减。

最常被引用的警示，是激素替代疗法（HRT）。20 世纪 80–90 年代的大量观察性研究发现：接受 HRT 的女性冠心病发病率显著更低，样本巨大、结论一致。医生因此广泛开具 HRT 以预防心脏病。

随后开展的随机对照试验（WHI）给出了相反结果：接受 HRT 的女性冠心病、中风与乳腺癌风险反而升高。观察性研究的假象从何而来？选择用 HRT 的女性往往社会经济地位更高、更注重健康、体检更频繁——这些“健康行为”同时降低心脏病风险。它们就是混杂变量。

同一问题，两种设计
观察性研究随机对照试验（WHI）
谁决定处理受试者/医生自己选择随机分配
混杂可能存在（如健康行为）期望上被均衡掉
结论HRT 降低风险HRT 升高风险

为什么样本量救不了

增大 n 只能减小随机误差，无法消除系统性偏差。只要混杂存在，更多的数据只会让你更精确地估计一个错误的关联。这正是观察性结论必须谨慎的原因。

HRT 与 WHI 的结果见文末来源；表中的对比为对研究设计的概括，不是新的数据。

03 · DAG 与后门准则

Judea Pearl 提出的有向无环图（DAG）用节点表示变量、箭头表示因果方向，把“应该控制哪些变量”从直觉变成了可推导的问题。图中从 X 到 Y、且第一步指向 X 的路径叫后门路径；它往往由混杂构成。

当后门路径上的变量 Z 可观测时，可以用后门调整公式估计干预分布：把数据按 Z 分层，求各层的条件关系，再用 Z 的分布加权平均。

P(Y∣do(X=x))=∑zP(Y∣X=x,Z=z)P(Z=z)
式 1

它把“看到 X = x”与“强制设定 X = x”区分开：前者记作 P(Y | X)，后者记作 P(Y | do(X))。只有阻断全部后门路径后，两者才相等。DAG 的作用，就是告诉你究竟该控制哪些变量。

DAG 正确性取决于领域知识

DAG 不是数据的产物，而是假设的表述。图画错了，因果结论就会错。它的最大价值是作为沟通工具：把“要不要控制这个变量”变成一张可讨论的图，而不是一句统计术语。此外，DAG 要求有向无环，不适合直接建模反馈回路。

04 · 随机对照试验

如果有一种方法能一次性消除所有混杂，那就是随机化。RCT 把参与者随机分配到处理组与对照组：因为分配与任何个体特征无关，两组在所有特征上（包括你没测量到的）期望上可比；两组结果的差异就可以归因于处理本身。用 DAG 的话说，随机化切断了所有指向 X 的箭头。

RCT 的局限与应对
局限说明应对
伦理不能随机让人吸烟或接触有害物自然实验、工具变量
外部有效性受试者未必代表目标人群实用性试验设计
成本大规模 RCT 昂贵准实验设计
非依从被分配处理却未实际接受意向治疗分析、工具变量
时效结果需长期才能显现谨慎使用替代终点

互联网行业的 A/B 测试就是 RCT 的一种：随机分配用户到旧版（对照）与新版（实验），再比较指标。它被称为“黄金标准”，不是因为它完美，而是因为它比其他方法更接近因果。

意向治疗（ITT）

当有人不依从时，按“原本被分配的组”分析（ITT）才能保持随机化的好处；按“实际接受了什么”分析会重新引入混杂。代价是 ITT 估计的是“被分配处理”的效应，而非“实际接受处理”的效应。

05 · Pearl 的因果阶梯

Pearl 把因果问题分成三个层次，后一层需要的信息比前一层更多。大多数数据分析停留在第一层，却常常用第一层的工具去回答第二层的问题。

  1. 关联：相关系数、回归、假设检验都在这一层；它只描述“看到的东西”。
  2. 干预：问“如果主动改变 X”。例如 P(溺水 | 冰淇淋多) 很高，但 P(溺水 | do(冰淇淋多)) 不变。
  3. 反事实：问“如果当时没做 X”。对应那条你从未观测到的路径，必须依靠因果模型推断。

越级的代价

要支持因果断言，要么做实验（第 2 层），要么用 DAG + 领域知识建立可识别的因果模型（第 2–3 层）。没有这些，任何“因果”表述本质上都是推测——无论它多“显著”。

06 · 动手：控制混杂

在下面这个教学模型里，X 对 Y 的真实效应固定为 3000；同时存在一个混杂变量 Z，它既抬高 X 也抬高 Y。拖动滑块改变 Z 对 Y 的影响强度，看不控制 Z 的朴素斜率如何被带偏。

控制与不控制混杂下的斜率

教学模型：X = Z + 噪声，Y = 3000·X + c·Z + 噪声。真实 X 效应为 3000；朴素斜率 ≈ 3000 + c/2。

当 c = 0（无混杂）时，朴素斜率就等于真实效应；c 越大，偏得越远。而只要控制住 Z，估计值就回到 3000 附近。这正是“分层”或“把协变量放进模型”背后的直觉。

07 · 自我检查与可复现计算

import numpy as np

rng = np.random.default_rng(0)
n = 2000
Z = rng.normal(0, 1, n)
X = Z + rng.normal(0, 1, n)                      # 混杂 Z 影响 X
Y = 3000 * X + 1000 * Z + rng.normal(0, 2000, n)  # 真实 X 效应 = 3000

print("朴素斜率:", round(np.polyfit(X, Y, 1)[0]))     # 3476，被混杂 Z 抬高
A = np.column_stack([np.ones(n), X, Z])
coef = np.linalg.lstsq(A, Y, rcond=None)[0]
print("控制 Z 后的 X 系数:", round(coef[1]))          # 2962，接近真实效应 3000

自我检查

问题：某公司发现“使用新功能的用户付费更高”，于是认为新功能提了收入。为什么不能直接下这个结论？

参考答案：“使用新功能”是用户自己选择的（非随机），可能存在混杂变量（如活跃度、付费意愿）同时影响“使用新功能”与“付费”。更可靠的做法是做随机化的 A/B 测试，或至少控制住可能的混杂变量，并对比控制前后的估计。

失败模式

两个常见错：一是把观察到的关联直接当作因果（越级）；二是控制了不该控制的变量——如果某个变量是“处理→结果”路径上的中间变量，控制它反而会引入新的偏倒。是否控制，要看变量在因果图中的角色，而不是看它是否“相关”。
