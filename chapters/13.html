Chapter 13 · Correlation

相关分析：先看散点图，再谈相关系数

“相关不等于因果”人人会背，但更常见的问题是：一个 r 值装不下关系的形状。同一个 r 可以对应一条直线、一条 U 形曲线，或一团被单个点拉歪的乱云。

贯穿案例：某数据集里“冰淇淋销量”与“溺水人数”高度正相关。这是否说明吃冰淇淋会导致溺水？我们该怎么用一张图和一个混淆变量把这件事说清楚？

01 · Pearson r：线性相关

Pearson 相关系数 r 度量两个连续变量之间线性关联的强度与方向。它把两列数据的离差标准化后相乘求和：

r=∑i(xi−x¯)(yi−y¯)∑i(xi−x¯)2∑i(yi−y¯)2
式 1

r 落在 [−1, 1]：接近 1 表示同向的线性关系，接近 −1 表示反向的线性关系，接近 0 表示没有线性关系。作为粗略经验，有人用 |r| ≥ 0.7 判为强、0.3 到 0.7 判为中等、低于 0.3 判为弱；但这些阈值与领域密切相关，不是普适标准。

02 · Spearman ρ 与 Kendall τ

当关系是单调但非线性（一直增或一直减，比如对数曲线），或数据含异常值、只是有序类别时，基于秩次的相关系数更合适。

Spearman ρ

把两列数据各自换成秩次，再对秩次算 Pearson 相关。它不要求正态，对异常值不敏感，能捕捉单调关系。

Kendall τ

基于“一致对”与“不一致对”的比例：随机取两个个体，变量大小顺序一致对上不一致对。小样本下分布更接近正态，解释也更直接。

三种相关系数的对比
系数类型适合的数据异常值敏感需要正态
Pearson r参数连续、线性很敏感是（推断时）
Spearman ρ非参数连续/有序、单调不敏感否
Kendall τ非参数连续/有序、单调不敏感否

三者不是“越新越好”的关系，而是针对不同关系的工具：线性且无异常值时用 Pearson，单调但非线或含离群值时用 Spearman 或 Kendall。

03 · 相关矩阵与热力图

多个变量一起分析时，会把两两相关系数排成相关矩阵，再用颜色深浅渲染为热力图。矩阵有助于快速发现成组的变量，但它同样只是线性关系的概括，不能代替逐对散点图。

import numpy as np
from scipy import stats

rng = np.random.default_rng(0)
x = rng.normal(0, 1, 200)
y = 0.6 * x + rng.normal(0, 0.8, 200)   # 教学构造的线性关系

print("Pearson :", stats.pearsonr(x, y))
print("Spearman:", stats.spearmanr(x, y))
print("Kendall :", stats.kendalltau(x, y))

热力图上的每一个格都是一个单独的推断。变量一多，两两比较的次数就急剧增长，未校正地解读“最显著的那一格”很容易得到假阳性（第 16 章）。

04 · 相关不等于因果

一个经典的真实例子：美国缅因州人均人造黄油消费量与离婚率之间的相关系数高达约 0.99（Tyler Vigen 的虚假相关图集）。这当然不能说明吃人造黄油导致离婚，最有说服力的解释是两者都随时间上升，属于巧合。

  1. 混淆变量：第三个变量同时影响两者（如气温）。
  2. 反向因果：可能是 B 导致 A，而非 A 导致 B（收入与健康就是典型）。
  3. 纯粹巧合：在足够多的变量对里，总能找到一些看起来很巧的相关。

三个问题过滤假相关

看到一个有趣的相关时，先问：1）有没有合理的因果机制？2）有没有可能的混淆变量？3）时间顺序是否合理（因在前，果在后）？三个问题能过滤掉大量虚假相关。第 17、27 章会用因果图与实验设计系统处理这个问题。

06 · 自我检查与可复现计算

import numpy as np
from scipy import stats

x = np.arange(1, 11.0)
y = x.copy()
print("无异常值 Pearson:", round(stats.pearsonr(x, y)[0], 3))   # 1.0

y2 = y.copy()
y2[-1] = 0
print("含异常值 Pearson:", round(stats.pearsonr(x, y2)[0], 3))
print("含异常值 Spearman:", round(stats.spearmanr(x, y2)[0], 3))

自我检查

问题：缅因州人均人造黄油消费量与离婚率的相关系数约 0.99。能否得出结论“人造黄油导致离婚”？

参考答案：不能。两者随时间缓慢变化，最合理的解释是共同的时间趋势而非直接因果。要检验因果，需要控制混淆变量或使用实验/准实验设计。

失败模式

只看相关矩阵而跳过散点图，会把 U 形关系（r≈0）误判为“无关”，也会把被单个异常值拉高的 r 当成真实趋势。去掉异常值前后分别报告结果，是更稳当的做法。
