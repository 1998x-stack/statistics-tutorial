Chapter 14 · Linear regression

简单线性回归：一条直线能说多少

相关分析只说“有关系”，回归要回答“X 每变化一个单位，Y 平均变化多少”。但一条画得出来的直线，也可能建立在站不住的假设上——所以算完系数，还得回头看残差。

贯穿案例：某团队用 10 位员工的“工作年限”预测“年薪”，拟合出斜率约 4 千元/年、R² ≈ 0.8。这条线能不能外推到 30 年工龄？那个 R² 又是否说明模型可靠？本章用可复算的例子把这两个问题说清楚。

01 · 模型与几何直觉

回归把两个变量的关系写成一条带误差的直线。它不再只问“有没有关系”，而是给出一个可解释的斜率：X 每增加一个单位，Y 平均变化多少。

y=β0+β1x+ε
式 1

β₀ 是截距（X = 0 时 Y 的期望），β₁ 是斜率（X 每增加一个单位，Y 的期望变化量），ε 是直线无法解释的部分。这里的 β₀、β₁ 是总体参数；样本上算出的 b₀、b₁ 只是它们的估计。

先看散点，再拟合

相关系数装不下的形状，回归线同样装不下。若散点呈弧形、分组或含极端点，直接套一条直线会把系统性偏差藏进残差里。拟合之前先看图，是本篇反复强调的第一步。

本页散点、系数与残差均为教学示意，用于演示公式与诊断，不来自任何真实数据集。

02 · 最小二乘法

把每个点的残差 eᵢ = yᵢ − ŷᵢ 平方后相加，得到残差平方和 SSE。普通最小二乘法（OLS）就是选让 SSE 最小的 b₀、b₁。对 SSE 分别关于 b₀、b₁ 求偏导并令其为零，可解出两个闭式公式：

b1=∑i(xi−x¯)(yi−y¯)∑i(xi−x¯)2
式 2
b0=y¯−b1x¯
式 3

b₁ 的分子与 Pearson 相关系数 r 的分子完全相同，因此 b₁ = r · (s_y / s_x)：相关性越强、Y 相对 X 波动越大，斜率越陡。这也解释了为什么 r 与 b₁ 符号总是一致。

把两个前提记牢

OLS 给出的是使平方误差最小的解，它本身不保证因果、不保证无偏、不要求 X 随机。斜率可解释的句子永远是：“X 每增加 1 个单位，Y 平均变化 b₁”，而不是“X 导致 Y 变化 b₁”。

03 · R² 与拟合优度

衡量直线拟合得好不好，最常用的是决定系数 R²。它把 Y 的总变异 SST 分成两块：模型解释了的 SSR，和残差留下的 SSE。

R2=1−SSESST=SSRSST
式 4

在本例中 R² = 3.6/6 = 0.6，与相关系数的平方 r² = 0.6 完全一致。R² 介于 0 和 1：越接近 1，直线解释的变异越多。但要用好它，得记住三个限制。

高 R² ≠ 模型正确

加入更多变量只会让 R² 不降，与变量是否有意义无关。简单回归里还要提防“虚假回归”：两个各自随时间上升的序列，即使毫无关系也可能给出很高的 R²。

低 R² ≠ 无关系

非线性关系、测量噪声大或总体本就不确定，都会压低 R²。低 R² 只是说“直线解释得少”，不代表斜率为零或没有信息。

两个时间序列的“漂亮”R²

Granger 与 Newbold（1974）证明：把两个相互独立的随机游走序列做回归，常得到很高的 R² 和看似显著的 t 值，实际却是伪回归。遇到时间趋势数据，先差分、看残差自相关，再谈 R²。

04 · 残差与 LINE 假设

系数和 R² 只描述样本内的拟合，不保证推断有效。OLS 的推断依赖四个假设，合称 LINE：线性（Linearity）、独立性（Independence）、残差正态性（Normality）、同方差性（Equal variance）。检查它们最直接的工具就是残差图。

正态性到底要紧吗

“残差要正态”主要影响小样本的推断（t 检验、置信区间）；点估计和 R² 本身不需要它。样本较大时，中心极限定理使系数的抽样分布近似正态，轻度偏态通常可接受。

05 · 影响点与虚假回归

并非每个点对直线的影响都一样。一个在 x 方向远离中心的点，即使残差不大，也可能把直线整体拽向自己——这叫高杠杆点。杠杆值只取决于 x 的分布，而与 y 无关。

离群点 vs 杠杆点

离群点是 y 方向偏离直线的点；杠杆点是 x 方向极端的点。一个既是离群又是高杠杆的点（强影响点）能单独改变斜率符号。

Cook 距离

把第 i 个点拿掉、重算系数，看估计变化多大。Cook 距离把“残差大”与“杠杆高”合在一起，用于筛查强影响点（Cook, 1977）。

教学示意：人口与图书馆

设想用某地区的人口预测图书馆数量，很容易得到很高的 R²。但人口多、图书馆多，是因为两者都被“城市规模”推动，而不是人口能“造出”图书馆。把它当成模型去指导“先增人口再增图书馆”就是因果倒置。高 R² 只描述拟合，不回答机制。

前视偏差（look-ahead bias）

更隐蔽的危险来自数据本身：若自变量里混入了“未来才知道”的信息（例如用事后数据构造的预测变量），R² 会被岗高。这不是模型的功劳，而是信息泄露。建模前必须把每个变量的可获取时点写清楚。

发现强影响点后，正确做法不是直接删掉它，而是先问“它是录入错误，还是一个真实且重要的群体”。两种情形的处理完全不同：前者纠正数据，后者可能需要在报告里同时给出含与不含该点的结果。

本节的人口–图书馆与前视偏差均为说明性情景，不是引用自某项研究的实测结果。

07 · 自我检查与可复现计算

import numpy as np

x = np.array([1, 2, 3, 4, 5], dtype=float)
y = np.array([2, 4, 5, 4, 5], dtype=float)

b1 = np.sum((x - x.mean()) * (y - y.mean())) / np.sum((x - x.mean()) ** 2)
b0 = y.mean() - b1 * x.mean()
pred = b0 + b1 * x
sse = np.sum((y - pred) ** 2)
sst = np.sum((y - y.mean()) ** 2)

print("b1 =", round(b1, 3), " b0 =", round(b0, 3))
print("R^2 =", round(1 - sse / sst, 3))
# b1 = 0.6   b0 = 2.2
# R^2 = 0.6

自我检查

问题：某回归得到 b₁ = 0.6，能否说“X 每增加 1，Y 就一定会增加 0.6”？

参考答案：不能。“平均”两字不能省：0.6 是预期变化，个体值仍围绕直线波动（由残差描述）。而且这句话只在 X 的观测范围内、且线性假设成立时才有意义，更不能读成因果。

失败模式

最常见的两个错：一是把直线外推到观测范围之外（例如用 10 年工龄的样本预测 30 年工龄），线性关系往往不再成立；二是把高 R² 当作“模型对”或“有因果”的证明。R² 只度量拟合，不度量正确性。
